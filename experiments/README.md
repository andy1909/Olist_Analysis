# Experiments Directory

This directory contains archived hyperparameter tuning and model experimentation scripts
that were used during the development of the forecasting pipeline.

These scripts document the experimental progression that led to the final model design
(Lag-3 Constrained Hybrid Residual Forecasting: Holt-Winters + XGBoost).

## Files

| File | Purpose |
|------|---------|
| (archived) | Hyperparameter grid search scripts and feature experiments |

> **Note**: The final optimized parameters are consolidated in `scripts/run_forecasting.py`.
> These experiment files are kept for reproducibility and audit trail purposes only.
